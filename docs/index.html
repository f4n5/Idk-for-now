Technical notes 
Pipeline:
1. Linear scan for C table decimal-escape string literals (no catastrophic regex).
2. Parse ipairs({{a;b};...}) shuffle pairs, evaluate arithmetic, apply 1-based swaps to C.
3. Parse local P={k=expr,...} into a char→byte map (and reverse).
4. For each shuffled string:
   - decode decimal escapes → bytes
   - try standard Base64 → bytes
   - apply P-table substitution (forward / reverse)
   - rolling XOR with key derived from string length, index, and P values
   - LCG-style stream (Numerical Recipes constants used by several Luraph builds)
   - score printable ratio + keyword hits; keep best candidate
5. Highlight http / key / discord / webhook / loadstring / rbx etc.

If the sample uses a different outer envelope (base85+LZMA LPH), run an unpacker first
and feed the resulting Lua that still contains the C/P/shuffle form.
