What does Static do?

Linear-scans the Luraph C decimal-escape table, applies the ipairs shuffle, builds the P substitution map, then runs a multi-path decrypt (base64, P forward/inverse, rolling XOR, LCG, accumulating XOR, short brute, rot, hex, custom alphabets). Scores printable + keyword hits.

What is the honeypot / troll detector?

Flags scripts that decrypt back into the same Luraph shell (self-loop), identical stage payloads, recursive loadstring of the same blob, or VM output that is still a full C-table Luraph wrapper. Shows a red banner and aborts auto-chain so you don’t waste time or run bait.

WeAreDevs / Prometheus path

Detects WAD/Prometheus markers (wearedevs.net/obfuscator, constant array + custom base64 alphabet + PRNG decrypt). Extracts lookup alphabets, unrotates constant arrays when shift is recoverable, decodes custom base64, and tries the common PRNG stream (seed * 57 style / byte-wise XOR with shuffled charset). Best effort static — full VM still available via Execute Lua VM.

VM / Auto-Chain

Offline Fengari (no CDN). Hooks string.char, table.concat, loadstring, HTTP mocks. Auto-Chain peels nested loadstring stages until plaintext or honeypot. Large 10MB VMs can OOM on mobile — use desktop.

Why 0 juicy on static?

Application strings may only exist after the VM constant decoder runs, or they may be encrypted with a per-build key not present as a simple P-table. Run VM or Auto-Chain. If every stage is the same Luraph shell, it’s a troll.

Hex Viewer / Diff / AST / Keys

Tabs under results: Hex shows a 16-byte grid of the clean payload; Diff compares a source sample to decrypted text; AST/Flow is a heuristic call-flow (HttpGet, loadstring, webhooks, keys) not a full Luau AST; API Keys harvests AWS/OpenAI/Discord/GitHub/Slack/Stripe/Telegram/JWT patterns.

CORS proxy fetch

Enable the toggle, paste a raw script URL, Fetch → Analyze downloads via corsproxy.io (or your prefix) and runs static. Browser CORS still applies if the proxy is down.

Report Pack

Builds Markdown + JSON with obfuscator guess, webhooks, keys, URLs, and juicy strings for ScriptBlox / Discord reports. Also copies markdown to the clipboard.

MoonSec V3+

Detects the This file was protected with MoonSec V3.x banner and the :gsub('.+', function() … end) init. Static path extracts literals + best-effort XOR/shuffle. VM hooks string.gsub so init side-effects run; Auto-Chain strips the gsub head and peels nested return(function(...)).

Coverage / god-mode decrypt

Static candidates per string: raw, b64 (std/url/custom), P-map, rolling/LCG/acc XOR, single-byte, multi-byte, RC4, Vigenere, rot, ROL/ROR, NOT, reverse, delta, Base32, Ascii85, zlib-header strip, JSON unwrap, layered b64+xor/rc4. Detectors route MoonSec, Luraph, WAD, PSU/Pandora, Shadow, IronBrew/Aztup, bytecode VMs, loadstring wrappers. Auto-Chain peels wrappers + nested return(function). Nothing is 100% — custom per-build VMs still need Patch & Run / VM.

Encryptor — best-effort strong pack

Pastes your Lua → multi-layer pack: payload → RC4 → Base64 → decimal-escape string table → VM-ish loader with shuffle + rolling XOR. Harder than plain base64 loadstring, still client-side reversible if someone uses this same lab.
